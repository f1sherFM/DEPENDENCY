# История изменений

Версии обозначают этапы разработки. Даты релизов не восстанавливаются по предположениям; tags/releases не создаются автоматически. [Подробная история](docs/feature-history.md).

## Unreleased

## 0.9.0

- Сохранённые исследования: имя, заметка, фильтры/selected/focus и мировые координаты камеры, восстановление конкретного snapshot после перезапуска без анализа. Обновление/copy, подтверждённое удаление, optimistic revisions.
- Транзакционная SQLite migration 2 → 3 добавляет investigations; snapshots и parser cache сохранены. State version 1 проверяется отдельно. [Контракт](docs/investigations.md).

- QA: сводка покрытия отделяет типы ограничений анализатора и число случаев от неразрешённых/неоднозначных импортов, ошибок разбора и пропусков capture. Убрана формулировка «637 проблем»; известные Rust-ограничения описаны по-русски. Исходные записи и счётчики snapshots не изменены, факты покрытия учитываются даже при отключённых диагностических правилах.

- QA: ручные zoom/pan и «Вписать граф» больше не сбрасываются начальной камерой при ResizeObserver/reflow. Новый граф получает читаемый масштаб; явное вписывание сохраняется при resize, ручной масштаб достигает 2%.

- Локальное наблюдение за UI и readonly MCP/CLI: открытый snapshot, фильтры/геометрия графа, runtime errors, сохранённые результаты и доказательства. Opt-in, атомарные observation files, freshness, явный выбор нескольких сессий; SQLite и проекты не изменяются адаптером. [Использование](docs/agent-access.md).

- QA: оболочка ограничена размером окна; прокрутка рабочих областей не уводит header за экран. Граф использует оставшуюся высоту, контекст доступен в узком окне, навигация сбрасывает прокрутку раздела.
- QA: окно стартует maximized с minimum 800×560; browser layout regression проверяет 800×560, 1024×640, 1280×720, 1536×864 и 1920×1080 при DPR 1.25.
- Устранён цикл analysis.rs ↔ js_ts.rs: общие ImportDecl/Fact вынесены в parse_facts.rs; формат сохранённых фактов и parser cache versions прежние.

- QA: предупреждения покрытия сгруппированы с доступом ко всем местам; счётчик навигации показывает архитектурные предупреждения отдельно от ограничений анализа.
- QA: встроенные `node:test`, `node:test/reporters`, `node:sea`, `node:sqlite` больше не считаются npm-пакетами; общие ограничения Rust/Python находятся в профиле, а не в ошибках разбора.
- QA: граф открывается с читаемым масштабом и скрытыми внешними пакетами; полное вписывание доступно отдельно.
- `analysis.exclude` исключает файлы и манифесты из индекса; шаблоны сохранены в профиле снимка. Собственные тестовые fixtures исключены конфигурацией репозитория. AST-кэш и история сохранены.

- QA: карточка текущего проекта в sidebar теперь открывает выбор папки; раньше это был статический блок без обработчика.

- QA: preview-узел открывает полный граф; недоступные настройки явно отключены.

- QA: исправлено обрезание правого столбца и нижнего ряда в предпросмотре графа из 36 узлов.

- QA: обработка ошибок/отмены системного выбора папки и блокировка повторного запуска во время диалога.
- QA: Rust resolver больше не создаёт связь при super traversal выше корня crate; профиль rust-resolver-2, без сброса AST cache.
- [Проверки 0.9 и оставшиеся ограничения покрытия](docs/version-0.9-validation.md).

- Оформление README, руководство разработки, roadmap, contribution guide и MIT license file согласно Cargo metadata.
- Windows CI и offline-проверка версий/ссылок документации.
