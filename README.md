# DEPENDENCY

DEPENDENCY is a local desktop tool for exploring software architecture, dependency graphs, code health, and the impact of changes.

The initial target is Windows 10/11. The planned stack is Tauri 2, React, TypeScript, Rust, and SQLite. Analysis is local and must never execute the inspected project's code.
