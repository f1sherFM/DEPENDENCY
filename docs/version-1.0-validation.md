# 1.0.0 Open Beta

Дата: 2026-11-14. Целевая платформа: Windows x64.

## Содержание

- Обзорная карта: каталоги, раскрытие, направленные связи с исходными местами и явными лимитами.
- Маршрут карта → файл → основания связей → Impact → исследование; возврат сохраняет контекст и камеру.
- Rust workspace path dependencies; Python статические bindings/from-import/reexports, namespace packages и синтаксис параметров типов Python 3.13.
- Выводы Impact сохраняются в заметке; граф исследования показывает потребителей первого исходного файла, а не полную сохранённую выборку Impact.
- Переносимый JSON v1: снимок, inventory, заметка и граф без исходников и parser cache. Preview и подтверждение; отдельные ID; транзакционный импорт без замены latest/history/cache.

## Проверки

До подготовки выпуска: 78 Rust tests passed, 3 profiling/export tests ignored в обычном наборе; 24 Node tests passed; TypeScript/Vite, Clippy с warnings denied и repository checks прошли. Браузерные сценарии используют настоящие engine exports и подменяют только Tauri transport. Проверены история, граф, Impact, исследования, экспортный вызов и отмена импорта после preview. Native tests проверяют перенос без исходников, версии, изменение файла, rollback и неизменность истории/кэша.

Windows NSIS установщик 1.0.0-beta.1 собран; владелец установил и сообщил, что основные функции работают. Это общая ручная проверка, не отдельное подтверждение каждого сценария обновления/отката, нативного диалога и большого проекта. Итоговый 1.0.0 отличается номером версии и документацией. Отчёт не утверждает отсутствие багов.

## Ограничения

- Анализ статический. Rust macros/cfg и Python runtime не исполняются; динамические или неоднозначные зависимости могут отсутствовать. Покрытие показано отдельно от архитектурных проблем.
- Git repository-only профиль не использует внешнее окружение; рабочий capture не является атомарным снимком файловой системы.
- Impact показывает потенциальных потребителей, а не прогноз поломки или гарантию достаточности тестов.
- Импорт требует выбранного локального проекта. Связь импортированных путей с его исходниками не подтверждается. Неизвестные форматы отклоняются; автоматической миграции переносимого файла нет.
- Переносимый файл содержит пути, имена, Git metadata и заметки. Перед передачей проверьте их. SHA-256 — контроль целостности, не подпись издателя. Установщик не подписан сертификатом издателя.
- На больших графах действуют явные ограничения отображения; native UI/performance ещё требуют обратной связи.

## Обновление и обратная связь

Закройте приложение и скопируйте весь каталог `%APPDATA%\com.f1sherfm.dependency` для резервной копии. SQLite schema 3 и graph state 1 сохранены; обновление не пересоздаёт базу. Для отката используйте резервную копию при закрытом приложении.

В баг-репорте укажите версию, Windows/масштаб экрана, шаги, ожидаемый и фактический результат. Не прикладывайте рабочую SQLite-базу или приватные исходники публично. Новые функции отложены до обратной связи; исправления beta выходят отдельными patch-версиями.
