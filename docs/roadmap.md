# Направление развития

Вехи ориентировочные. Цель — полезный личный инструмент с понятными границами анализа.

| Версия | Содержание | Состояние |
| --- | --- | --- |
| 0.1 | JS/TS AST и реальный граф | Реализовано |
| 0.2 | SQLite, снимки, AST cache | Реализовано |
| 0.3 | Улучшенный JS/TS resolver | Реализовано |
| 0.4 | Интерактивный граф | Реализовано |
| 0.5 | Архитектурные диагностики | Реализовано с ограничениями |
| 0.6 | Файловый Impact | Реализовано |
| 0.7 | Локальный Git и сравнения | Реализовано |
| 0.8 | Базовая поддержка Rust/Python | Реализовано с ограничениями |
| 0.9 | Проверка продукта, исправления, сохранённые исследования | Реализовано; оставшиеся native-проверки отмечены в отчёте |
| 1.0 | Исследование реальных Rust/Python проектов и понятная карта | Open Beta: [проверки и ограничения](version-1.0-validation.md) |

Проведён основной QA: тесты, анализ кода, browser UI, чтение состояния и доступные native-сценарии. Результаты и оставшиеся проверки — в [отчёте](version-0.9-validation.md).

Для 0.9 реализованы [сохранённые исследования](investigations.md): имя, заметка и обычный граф на неизменяемом снимке. Перенос на новый снимок не выполняется автоматически. В 1.0 добавлены обзорная карта, переходы с сохранением контекста, улучшения Rust/Python и перенос исследований. Дальнейшие исправления определяются обратной связью по beta.

«Реализовано» не означает отсутствие багов или опубликованный GitHub release. Проверки описаны в version-*-validation.md. Текущее состояние: [README](../README.md).
