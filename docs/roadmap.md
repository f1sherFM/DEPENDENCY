# Направление развития

Вехи ориентировочные. Цель — полезный личный инструмент с понятными границами анализа.

| Версия | Содержание | Состояние |
| --- | --- | --- |
| 0.1 | JS/TS AST и реальный граф | Реализовано |
| 0.2 | SQLite, снимки, AST cache | Реализовано |
| 0.3 | Улучшенный JS/TS resolver | Реализовано |
| 0.4 | Интерактивный граф | Реализовано |
| 0.5 | Архитектурные диагностики | Реализовано с ограничениями |
| 0.6 | Файловый Impact | Реализовано |
| 0.7 | Локальный Git и сравнения | Реализовано |
| 0.8 | Базовая поддержка Rust/Python | Реализовано с ограничениями |
| 0.9 | Проверка продукта, исправления, сохранённые исследования | Обсуждение, функции не реализуются |
| 1.0 | Согласованный объём, проверенный в ежедневной работе | Планируется |

Сейчас разрешён отдельный объём: оформление репозитория, документация и автоматические проверки. Проверка продукта через UI и разработка исследований в него не входят.

Для 0.9 предложено сохранять название, заметку и состояние обычного графа, привязанное к неизменяемому снимку. Контракт восстановления и переноса на новый снимок нужно согласовать до реализации.

«Реализовано» не означает отсутствие багов или опубликованный GitHub release. Проверки описаны в version-*-validation.md. Текущее состояние: [README](../README.md).
